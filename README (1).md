# BIT235Workshop2

Workshop 2 – Fundamental Programming Structures in Java (Variables, Primitive Datatypes and String)

## Files

| File | Exercise |
|---|---|
| `Exercise1_1.java` | Difference of two numbers (Scanner input) |
| `Exercise1_2.java` | Celsius to Fahrenheit conversion |
| `Exercise1_3.java` | Area of a circle (pi = 3.14, Math.pow) |
| `Exercise1_4.java` | Compound interest: A = P * (1 + r)^n, P = $5000.00, r = 4%, n = 10 |
| `Exercise1_5.java` | Volume of the Earth and the Sun, and their ratio |
| `Exercise1_6.java` | Fuel consumption on normal and rough roads |
| `Exercise1_7.java` | String exercise: `"I love java programming".substring(7, 11)` → prints the result `"java"`, length 4 (written-answer question, demo program included) |
| `Exercise1_8.java` | Compare two strings (equals, charAt) |

## Compile and Run

```bash
javac Exercise1_1.java
java Exercise1_1
```
